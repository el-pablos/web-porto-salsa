## 🎯 Deskripsi Projek

Website portfolio pribadi buat **Adinda Salsa Aryadi Putri** — mahasiswi Sosiologi FISIP Universitas Nasional (UNAS) yang punya passion di bidang Data Analysis, Social Research, dan teknologi. Website ini dibangun pake **Next.js 14** dengan **TypeScript**, **Tailwind CSS** buat styling, dan **Framer Motion** buat animasi yang smooth dan interaktif.

Desainnya pake **tema pink pastel soft** yang feminin dan elegan dengan glass morphism effect, blob morphing background, sparkle cursor trail, dan berbagai micro-interactions lucu yang bikin pengalaman browsing jadi menyenangkan. Semua konten diambil dari satu sumber data (`portfolio.json`) yang memudahkan update tanpa harus ubah kode komponen.

Website ini menampilkan **10 section utama** yang mencakup:
- **Profil & Bio** — perkenalan lengkap dengan highlight kemampuan
- **Keahlian** — 5 kategori skill (Data Analysis, Visualization, Database & Query, Tech Tools, Soft Skills)
- **9 Proyek** — gabungan proyek data analysis, creative, tech, sociopreneurship, dan research
- **5 Pengalaman** — magang di KND, organisasi UNAS FEST & YRI, pengabdian masyarakat ARKEDUNA, volunteer Generasi Bebas Plastik
- **6 Sertifikat** — dari berbagai kegiatan organisasi dan volunteer
- **8 Desain** — galeri infografis, poster, sticker, dan logo
- **Kontak** — form email, LinkedIn, GitHub, Instagram, telepon
- **Statistik** — counter animasi proyek, dataset, tools, sertifikat, tahun belajar

Semua section **full responsive** — mobile-first design yang optimal di HP, tablet, dan desktop. Plus ada **easter eggs** tersembunyi yang bikin website ini lebih fun!

Live di **[salsa.tams.codes](https://salsa.tams.codes)**.

## 🔄 Data Flow

Semua konten website diambil dari satu file: **`portfolio.json`** (Single Source of Truth). Ini bikin update konten jadi gampang banget — tinggal edit JSON-nya, ga perlu ubah kode komponen sama sekali.

```
portfolio.json (Single Source of Truth)
       │
       ├──→ Hero.tsx           → nama, title, tagline
       ├──→ About.tsx          → deskripsi, nama, pengalaman
       ├──→ Skills.tsx         → 5 kategori skill (20 items)
       ├──→ Projects.tsx       → 9 project cards + tech tags + links
       ├──→ Experience.tsx     → 5 pengalaman + 1 pendidikan
       ├──→ Certificates.tsx   → 6 sertifikat
       ├──→ DesignGallery.tsx  → 8 desain (infografis, poster, sticker)
       ├──→ Contact.tsx        → email, phone, LinkedIn, GitHub, Instagram, lokasi
       ├──→ VisitorCounter.tsx → 5 stats (proyek, dataset, tools, sertifikat, tahun)
       └──→ Footer.tsx         → nama, GitHub, LinkedIn, Instagram
```

## 🥚 Easter Eggs

Website ini punya beberapa easter egg tersembunyi yang bikin pengalaman jadi lebih fun:

1. **Confetti Burst** — Klik nama "Salsa" di Hero section 5 kali berturut-turut, confetti bakal meledak!
2. **Walking Chicken** — Ada ayam lucu yang jalan-jalan di bawah layar. Klik ayamnya 10 kali buat bikin dia bertelur!
3. **Egg Collection** — Kumpulin telur dari ayam dengan klik telurnya. Ada counter yang nunjukin berapa telur yang udah dikumpulin.
4. **Heart Burst** — Klik di mana aja di halaman, heart particles bakal muncul!
5. **Idle Avatar Peek** — Diemin website 45 detik tanpa interaksi, avatar bakal ngintip dari samping layar.

## 📱 Responsive Design

Website ini dibangun dengan pendekatan **Mobile-First Design**. Semua komponen di-optimize buat 3 breakpoint utama:

| Breakpoint | Lebar | Target Device |
|---|---|---|
| **Default** | 0px+ | HP kecil (iPhone SE, dll) |
| **sm** | 640px+ | HP besar, tablet portrait |
| **md** | 768px+ | Tablet landscape |
| **lg** | 1024px+ | Desktop |

### Responsive Features
- **Grid layouts** berubah dari 1 kolom (mobile) → 2 kolom (tablet) → 3 kolom (desktop)
- **Font sizes** scale up dari mobile ke desktop (text-sm → text-base → text-lg)
- **Padding/margin** responsive (p-4 → p-6 → p-8)
- **Navbar** collapse jadi hamburger menu di mobile dengan focus trap
- **Timeline** left-aligned di mobile, center-alternating di desktop
- **Touch targets** minimal 44x44px buat mobile
- **No horizontal scroll** di semua viewport

Setiap push ke branch `master` otomatis trigger pipeline:

```mermaid
flowchart LR
    A[Push/PR] --> B[Lint Job]
    A --> C[Test Job]
    B --> D[Build Job]
    C --> D
    D --> E[Release Job]

    style A fill:#FF99C8,color:#fff

    style E fill:#9ED2D6,color:#fff
```

### Pipeline Steps

1. **Lint** — ESLint check kode quality
2. **Test** — Jalanin 79 unit tests, harus 100% passed
3. **Build** — Build production Next.js
4. **Release** — Auto-create GitHub Release (latest + versioned) dengan changelog

### Release Strategy
- **Latest Release** — selalu update ke commit terbaru (`latest` tag)
